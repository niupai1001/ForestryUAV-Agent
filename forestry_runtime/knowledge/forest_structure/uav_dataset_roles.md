# 林业 UAV 数据角色与批次边界

## 必须分开的角色

一次数据盘点至少区分主航线影像、起飞前参考板、起飞后参考板、派生 RGB/CIR、已有正射/DSM/DTM/CHM 和无法归类文件。参考板用于辐射校准证据，不是林区航线覆盖，不能因为位于同一父目录就计入主航线影像数或摄影测量曝光组。

不同相机、日期或时间段、地理范围、波段组合应视为不同采集组。多光谱同步曝光应按 CaptureUUID 等相机元数据分组；只有文件数量相等而没有同步标识，不能证明各波段一一对应。

## 多光谱判断

波段角色必须来自影像 XMP/EXIF、成果波段描述或维护者资料，不能仅按波段数量猜测。OpenDroneMap 官方多光谱文档说明，多相机系统的各传感器波段应作为同一采集处理，输出通常包含每个相机波段并可能附加 alpha；是否采用相机辐射校准取决于传感器与元数据条件。

来源：<https://docs.opendronemap.org/multispectral/>

DJI Mavic 3M 官方规格给出的多光谱配置是 Green、Red、Red Edge、NIR，分别约为 560±16、650±16、730±16 和 860±26 nm；这只能用于确认 Mavic 3M，不应套用到 FC6360 等其他相机。

来源：<https://enterprise.dji.com/mavic-3-m/specs>

## GPS 与 RTK 边界

影像包含 GPS 只证明存在可识别坐标。影像存在 RTK 字段或数值状态码也不证明固定解、厘米级精度或坐标基准正确。只有同时取得厂商状态定义、固定解状态、基站或网络改正来源、坐标参考以及独立检查点残差时，才能报告相应定位精度。

DJI 官方规格中的 RTK 精度是设备在明确工作条件下的规格，不是任意航片文件的实测误差。项目交付仍需记录本次飞行的实际解状态与检查证据。

来源：<https://enterprise.dji.com/mavic-3-m/specs>
