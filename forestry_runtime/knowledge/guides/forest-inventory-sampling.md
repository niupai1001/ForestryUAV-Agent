# 林业样地、参考标签与面积精度评估

- 明确总体、抽样单元和目标量：单木、样地、像元和区域面积不可混作同一种统计单位。
- 地图精度评估应有概率抽样或说明偏离概率抽样的后果；参考标签在时间与空间上要足以代表被评估单元，并尽量独立于制图过程。
- 对类别面积，应同时报告地图直接计数与基于参考样本的面积估计，尤其在分类误差明显时；给出混淆矩阵、用户/生产者精度及不确定区间。
- 缺少独立参考样本时可报告地图内部统计量，不能报告经验证的分类精度或把地图面积当作无误差真值。
