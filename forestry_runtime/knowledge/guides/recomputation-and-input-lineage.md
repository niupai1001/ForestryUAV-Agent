# 输入变更后的重算与结论血统

## 什么时候必须重算

只要参与计算的输入发生了变化，旧结果就不再对应当前输入，必须重新执行。
输入变化以**内容身份**判断，而不是文件名或修改时间：同名文件内容不同仍是变化，
不同名文件内容相同仍可复用。

判断顺序：

1. 记录每个输入的内容身份（大小与哈希）；
2. 比较当前输入与产出该结果时的输入身份；
3. 身份不同就必须重算，并在新结论中引用新的输入身份。

## 常见错误

- 代码没变就认为结果没变。输入变了、代码不变时，结果必须是新的。
- 结果文件存在就当成已完成的证据。文件存在只说明曾经写过一次。
- 重算后仍然引用旧输入的名称或旧参数，使新结论无法对应新输入。
- 用修改时间做判断：复制、解压和同步都会改变修改时间而不改变内容。

## 报告要求

重算后的报告必须说明：上一版结论对应的输入身份、本次输入身份、以及本次执行确实
发生过的证据（新的作业或执行记录）。只声明“已更新”而没有执行证据，不构成重算。
