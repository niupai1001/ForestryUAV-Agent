# 林业 UAV 数据角色与批次边界

## 必须分开报告的角色

盘点时必须把以下角色分开列出，不得合并成一个“影像数量”：

- 主航线影像；
- 起飞前参考板与起飞后参考板；
- 已派生的 RGB / CIR 成果；
- 已有的正射、DSM、DTM、CHM；
- 无法归类的文件。

参考板是辐射定标证据，不是林地覆盖。它与主航线影像位于同一父目录，并不使它可以
计入主航线影像数量或摄影测量曝光组。

## 批次划分

相机不同、日期不同、地理范围不同或波段组合不同，都属于不同的采集批次。
多光谱同步曝光应按相机元数据（例如 CaptureUUID）分组；文件数量相等本身不能证明
波段一一对应。

波段角色必须来自 XMP/EXIF、产品波段描述或维护者材料，**不能由波段数量推断**。
DJI Mavic 3M 的 Green/Red/RedEdge/NIR（约 560±16、650±16、730±16、860±26 nm）
只对 Mavic 3M 成立，不得套用到其他相机（例如 FC6360）。

## 定位质量

GPS 字段存在只说明存在一个坐标。存在 RTK 字段或数值状态码，不等于固定解、
厘米级精度或正确基准。要报告定位精度，必须同时具备：厂商状态码定义、固定解状态、
基站或网络校正来源、坐标系，以及独立检查点的残差。

厂商给出的 RTK 指标是设备在声明条件下的规格，不是任意一张影像的实测误差。
