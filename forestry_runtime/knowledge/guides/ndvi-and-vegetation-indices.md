# NDVI 与植被指数计算约定

本指南只约束 NDVI/植被指数计算。RGB 影像缺少 NIR 时不能计算 NDVI，
但仍可用颜色、纹理和标注进行可见树冠分割及覆盖率估计；见 `rgb-canopy-cover`。

## 波段选择

NDVI 使用 `(NIR - Red) / (NIR + Red)`。红光与近红外波段必须由波段描述、XMP/EXIF
或维护者材料确定，不能按波段序号猜测。波段顺序存疑时先检查波段描述再计算。

若产品记录了比例因子和偏移量，应按产品定义还原各波段量值后再解释指数。
两波段具有相同的纯乘法尺度时，该尺度会在 NDVI 比值中抵消；非零偏移量、
不同尺度、非反射率输入或有符号/无效值仍可能改变结果。不能仅凭整数存储
断言 NDVI 会超出 [-1, 1]。换算参数应来自产品元数据或可核查说明。

## 有效值与掩膜

分母为零的像元必须判为无效，而不是产生无穷大或 NaN 后被静默改写。
输出栅格必须继承输入的坐标系、仿射网格与掩膜：NoData 区域在输出中仍然是 NoData。

统计口径要明确：统计量只在有效像元上计算，并同时报告有效像元数与缺测比例，
否则同一份数据可以得出互相矛盾的“平均值”。

## 报告一致性

交付报告中的统计量必须与交付栅格一致，并且可以从栅格重新计算出来。
只报告一个数字而不说明它的分母、掩膜约定和波段来源，不构成可核对的结论。
