# 栅格对齐、掩膜与分区统计

## 对齐

两个栅格参与同一计算前，必须确认：坐标系相同、仿射网格相同（原点与像元大小）、
尺寸相同。任一不同都需要一次**有记录**的重采样。

重采样方式须与变量含义和目标分辨率匹配：连续量可选双线性、三次或面积平均等；
类别量通常选最近邻或众数，不能用双线性插出虚假的类别编码。重采样会改变连续量，
因此要记录方法，不能把插值值当作原始观测。

地理坐标系（EPSG:4326 一类）的像元大小单位是度，不是米。没有执行有依据的投影换算时，
不得把像元大小标成米，也不得直接用度数计算面积。

## NoData 与掩膜

NoData 值、alpha 通道、内部掩膜与外部掩膜都可以表示无效区域。转换或重采样后要
重新确认掩膜语义，避免把 NoData 当作 0 参与统计。

注意两套约定：rasterio 掩膜数组以 `True` 表示无效，GDAL 有效数据掩膜以非零表示有效。

## 分区统计

分区统计前必须确认分区矢量与栅格在同一坐标系下，并明确以下口径：

- 统计只使用落在分区内的有效像元；
- 一个分区内有效像元过少时，该分区的统计量不构成结论，应单独标记，而不是与其它分区混算；
- 面积由像元大小与投影单位推导，并在报告中写明单位；
- 边界像元是否计入（全包含、中心点包含）会改变结果，必须选定并记录一种口径。

分区统计的输出应能追溯到输入的栅格版本、掩膜定义和分区定义。
