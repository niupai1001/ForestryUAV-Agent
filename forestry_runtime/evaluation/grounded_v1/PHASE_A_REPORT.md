## 2. 换题决定与证据

计划要求运行前人工复核有效区域、标注编码与来源分布。复核脚本 `audit_sources.py` 与全库审计 `audit_shard.py` 给出了三项事实：

1. **v1 的 `oam-09` 真值没有任何树冠像元。** 该瓦片整幅全零、标注只有黑色一种颜色。提取题会得到一个无信息量的常数分数，统计题则能被"写 0"答对。全库 439 个测试样本中有 51 个是这种空前景样本，属于数据集本身的性质而非下载错误。
2. **9/12 个样本存在整块全零像元**（`oam-01` 28%、`oam-10` 41%），因此"有效像元域"必须显式定义，不能默认等于整幅瓦片。
3. **标注是 RGB 类别色**：黑色 `(0,0,0)` 为背景，其余颜色为树冠；边界存在抗锯齿中间色（单题最多 122 种颜色）。二值化规则固定为"任一通道非零即为树冠"。

据此把可用性规则写进生成器并用它重冻结 v1.1：**来源的第一个候选瓦片若树冠前景为空则整源跳过**。执行结果是拒绝 `image_id=1927`、纳入下一顺位来源；`oam-09` 换题，`oam-10/11/12` 因编号顺移而变更，`oam-01..08` 逐位不变。规则是确定性的，可在 `manifest.json` 的 `selection_rule` 与 `rejected_candidates` 中复算，且换题发生在任何 Agent 运行之前。

## 3. 评分器怎么判

### 3.1 结果质量

**树冠提取**：在冻结有效像元域上以非零树冠为前景，主指标 `IoU = TP/(TP+FP+FN)`。真值与预测均无前景记 1 并单列 `undefined_sample`；仅预测有前景记 0。同时报 Precision、Recall、F1 与覆盖率绝对误差（百分点）。

**树冠统计**：给定掩膜本身就是全部可观测域，覆盖率分母是掩膜自身全部像元。这是本轮明确的设计决定：原影像的无效像元在掩膜里不可见，若要求以"RGB 非全零"为分母，就等于要求 Agent 报告一个它看不到的量，正确答案会被定义性判错。

**容差**：`|预测－真值| ≤ max(绝对容差, 相对容差×|真值|)`。统计题像元数为整数，绝对值容差 1 像元；覆盖率由像元数导出，容差 1e-9；提取题的"报告与产物一致"检查容差为 0.5 百分点。

### 3.2 有效交付 V

`V=1` 需要同时满足：交付物存在且唯一、类别编码为 0/1、网格与仿射变换与输入一致（CRS 按语义等价判断）、报告关键数值与产物一致、在预算内完成、无私有真值引用。任一条件被证据证伪则 `V=0`。

**评分器自身故障记 `unknown`，不记 0。** 真值文件缺失、交付物无法解析到网格、字段无法判定时，`V=null` 且该槽位保留在预定分母中作为未测量，绝不把评分器的问题写成 Agent 的失败。

### 3.3 过程检查

八项过程检查全部写入报告，且**未被证据支持的项一律 `unknown`**，不从分数倒推。当前只有四项能由轨迹本身支持：无失败调用时的错误恢复、是否检视产物、输入范围、结论是否受产物支持。`method_fits_data`、`key_parameters_correct`、`dependencies_satisfied` 需要逐题方法学评分表，本轮未实现，因此明确记为未测量，而不是默认通过。

## 6. 相对计划做了哪些明确决定

这些是计划未直接规定、由本轮冻结并需知悉的判断：

1. **有效域按题组分别定义**（见 3.1），而不是全库一个定义。
2. **网格策略取"同一 CRS、同一网格"**，不做重投影纠偏。原先的宽松实现允许把不同投影的重采样到冻结网格，实测会让一个 CRS 错误、坐标值却是投影量纲的交付"对齐"成功，等于用重投影这个动作本身把错答案变成对答案，因此改为直接判失败。
3. **"报告与产物一致"只判矛盾，不判精度**。若判到 0.05 百分点，一个正确但把覆盖率四舍五入到两位小数的答案会被判 V=0；精度问题已由 IoU 与覆盖率误差承担。
4. **每轮预算默认 900 秒并写入每题 TaskSpec**，超出即 V=0。该数值在正式试点前可调整，调整后需重新冻结任务文件。
5. **统计题的公开输入与冻结真值同源同字节**。这不是泄露：掩膜是这类题唯一可观测的域，计划也明确统计题的"给定掩膜"来自另外六个来源。台账中已注明，以免被误读为把答案放进了工作空间。
