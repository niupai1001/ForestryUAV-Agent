## 原始产品目标与范围

原文要求单人本地使用的通用Agent，同时具有真实无人机影像和LiDAR能力。非专业用户提供本地数据与自然语言目标后，应用负责检查条件、选择方法/参数、准备依赖、执行长任务、验证文件并交付中文报告。固定科学工具可运行，是实现这个目标的基础；领域自主规划和完整UI业务闭环仍需交付。

完整范围包含R01–R16、U01–U08和AC-01–AC-13。用户明确暂缓Agent联网搜索；其余范围未缩减。物种、异速生长/生物量、多光谱指数等为条件能力；飞行规划、无人机控制和多用户云平台不在首期。

## 实际框架与原文选型调整

当前使用模块化本地应用与隔离Worker：一个FastAPI服务、一个React工作台、应用SQLite权威状态和现有持久Jobs。Agent执行框架为PydanticAI，Harness提供原生检查点、上下文管理、工具输出处理与SubAgents。原文LangGraph是条件复用建议；实施计划选择复用已有PydanticAI/Harness，避免再建循环和第二份任务事实源。

| 层次 | 实际选型 | 原文行为职责 |
|---|---|---|
| 应用/契约 | Python3.12、uv.lock、Pydantic v2 | 类型边界、配置/规范修订、显式单位与未知值 |
| 本地服务/界面 | FastAPI/Uvicorn、SSE；React19/TypeScript/Vite | 同一UI/API、进度/控制/产物检查 |
| Agent/上下文 | PydanticAI、PydanticAI Harness | 原生工具循环、检查点/压缩、隔离角色；应用仍管理验收与权限 |
| 本地模型 | Ollama，本地OpenAI-compatible协议；Qwen3.8-27B和Qwen3.5-4B配置 | 本地模型/模板身份、用量与错误；不自动转云 |
| 权威状态/知识 | SQLite/WAL/事务/CAS；FTS5/BM25 | 任务、动作、授权、作业、证据；本地全文检索，语义索引/OCR为可选 |
| 执行隔离 | Docker/WSL2；固定镜像与资源限制 | 原源只读、断网非root执行、实际取消/恢复和产物发布 |
| 点云 | laspy/pyproj；PDAL2.9.3 | 字段/CRS检查、分类/地形/表面/HAG |
| 冠层/空间 | R4.4.3、lidR4.2.3、Rasterio、terra、sf | CHM、种子/实例、支持、ID与矢量/指标；ROI代码尚待验收 |
| 影像，待实现 | ODM/NodeODM与GDAL/Rasterio | 原始航片重建与窗口处理 |

通用环境和GIS/R运行时分开锁定。当前科学镜像已实际使用，包锁已保存；重建配方存在不等于干净机器安装已经通过。原文硬件是5090/128GB RAM/约1TB可用盘的开发参考，不能由此推导低配或数百GB能力已经验证。

运行原则是“模型提案 → 应用检查授权/修订/预算 → 持久Job真实执行 → 产品读回与检查 → 中文报告/用户验收”。模型回复、计划勾选和工具退出码分别是过程信息，不单独证明任务或科学精度完成。H0是直接循环，H1加入任务/检索/上下文管理，H2再加入隔离角色；正式比较共用数值执行器、权限和资源保护。

## 两条科学流水线及指标原理

影像原文完整路线：原始重叠RGB航片 → ODM正射/DSM → 有效ROI/支持 → RGB代理与有依据冠层分支 → 指标/质量图/报告。ExG使用归一化RGB的2g-r-b与固定直方图Otsu，语义是可见绿色代理，不能直接称林分冠层覆盖。V1还必须实现兼容DTM水平对齐后H=DSM-DTM、H≥2米高度规则、支持/排除面积与覆盖百分比；无兼容地形或冠层专用证据时，冠层指标不可用。RGB没有NIR，NDVI不能补造。

LiDAR已实现路线：原始LAS → 字段/CRS/垂直/单位检查 → 新SMRF地面分类 → 1米IDW DTM和同网格最大值DSM → 地面支持与HAG → 0.5米无填洞p2r CHM → 5米LMF窗口/2米hmin种子 → Dalponte冠层实例 → 原始Z分割LAZ、GPKG、ID/UID、指标和报告。10米最大树冠直径按0.5米解析为20像素。原分类/额外oracle标签不参与预测；负残差保留，最终treeID=0表示未分配。默认参数是bootstrap配方，不是验证过的最优参数。

真实flight02已有1156172点、48个高冠层候选、2317.5平方米共同有效支持的交付及读回证据。该领域流程由操作者通过真实API/Jobs驱动，模型请求为0，不能算领域自主完成率。主服务尚未统一加载新领域API，领域实算/界面在独立开发状态核对。

原文指标范围还包括：有效面积、可见绿色代理、可见性不明确面积、两类冠层覆盖、CHM p95、检测数量/密度、每树顶高/树冠面积/等效直径、类别面积及条件NDVI。当前只交付部分点云指标：整架次支持面积、数量/密度及每实例高度/面积/直径。完整MetricSpec、ROI边界权重、精确统计/缺失/支持血缘及影像指标未收口。公式必须绑定支持区域：面积=sum(像元权重×面积)，密度=接受实例数/有效公顷；零或未知支持为不可用，不能写成零密度。
