# 显式长期记忆

长期记忆沿用现有 `Memory`、认证 API 和 SQLite，不增加独立 Agent、经验提升循环或模型写入工具。用户在设置页填写内容、来源与依据、适用条件、局限、可选到期时间及任务范围，预览后明确保存。来源说明是用户声明，不自动成为已验证证据，也不能授予文件、执行或联网权限。

`POST /memory` 保存版本 1。`PATCH /memory/{id}` 提交完整内容和 `expected_version`，保存下一版本；过期的编辑版本返回 409，先重新读取再修改。`DELETE /memory/{id}` 同样要求 `expected_version`，停用并保留下一版本，返回 `status=forgotten`。停用记录不能经更正自动重新启用；用户可以明确保存新记忆。三个写入边界只接受认证用户请求，拒绝伪造用户事件、版本状态等额外字段。相同 request_id 的相同请求返回原收据，不产生新版本；不同请求复用该 ID 返回 409。

`GET /memory` 分页返回当前有效记录，`include_inactive=true` 供用户查看停用或过期记录。`GET /memory/{id}/versions` 分页查看历史内容、版本及对应真实用户事件 ID。历史只读；本次迁移把仍存在的旧笔记及原保存事件作为版本 1，不改原字节和旧请求收据。此前已物理删除的内容不能凭空恢复。

模型的 `read_user_memory` 只读取当前版本，机械过滤停用、到期和不匹配 `scope_task_ids` 的记录；公开任务拒绝读取。任务列表为空表示所有私密任务，非空表示仅所列任务。有效期必须带时区，存储时规范为 UTC。来源、适用条件和局限随当前内容返回，模型使用前需核对；自由文本条件没有被宣称为自动科学验证。已发生任务的动作收据与模型输入保留历史，不因后续更正而改写。

本次定向验证覆盖版本保留、可信用户事件、幂等请求、旧版本冲突、停用、任务/公开范围、有效期、旧记录迁移和分页。真实浏览器验证覆盖预览前无写入、保存与刷新、更正与刷新、历史查看、停用后退出有效列表。浏览器使用 `workspace/memory-ui-20261010-v1` 的独立数据库，关闭 Agent；没有写入生产经验或重跑模型评测。当前界面诊断关闭联网搜索探测，符合用户暂缓搜索的范围。

这补齐 AC-09 的显式记忆实现和局部行为证据；中文知识导入、源冲突/条件检索及与完整任务的组合验收仍须阶段 1 出口证据，不以本条通过代替整个 AC-09。
