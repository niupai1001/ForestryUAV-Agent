# 显式知识导入与任务缓存

知识导入复用 `Documents`、原 SQLite FTS 中文分词和 `Knowledge`，没有新增检索后端或 Agent 循环。原 `index_document` 仍是授权任务资料的窗口缓存，不等于用户把资料加入可复用知识。模型没有 `knowledge.import` 写入工具。用户在“本地知识”界面选择已登记只读来源，填写分类、来源说明、条件和局限后，明确导入一页／窗口；下一页需单独确认。

`POST /knowledge` 是认证用户导入边界，记录真实 `explicit_knowledge_import` 事件及幂等收据。相同请求重放不重复导入，相同来源版本/窗口/元数据共用同一导入记录和原 FTS 块；改变请求不能复用旧 request_id。`expert_assertion`、`measurement`、`reference` 为用户分类，不能据此宣称科学测量已经验证。字段拒绝伪造用户事件、分类权限等额外授权。

完整原文件以 SHA-256 命名，保存在内部目录的不可变快照中，文本与页／字节窗口锚点、源版本、SHA 和来源数据分类一起持久保存。已存在快照再次核验，复制时复核源版本与字节摘要。单文件导入限 128 MiB；大于此限制需缩小授权知识文件，不能据此宣称支持任意大小专家库。格式、加密、空页及 OCR 能力继续原读取器边界，不新增 OCR/embedding。

`GET /knowledge` 分页查看来源状态；`GET /knowledge/{id}/content` 读取历史提取文本及引用，先复核快照并确认原资源授权仍在。来源改版或读取器改版后的显式导入标记旧导入为 superseded，保留旧快照、文本及用户事件。源缺失、版本/字节改变、快照损坏或授权撤销，检索不再返回该导入的建议。撤销后也拒绝重新播放导入响应；不以任务缓存绕过损坏导入。

`POST /tasks/{task_id}/knowledge/search` 和模型 `search_knowledge` 使用同一个检索实现，只返回任务当前授权输入交集，委派还取角色 effective_input_refs 的交集；公开任务不能读私密知识。中文词策略仍为汉字与双字组合。来源、条件、局限和用户分类分别返回，冲突来源各自保留，不自动裁定意见或把断言改写成实测证据。来源通知用于显示过期/替代/不可用状态。FTS 候选上限 500，按来源先保留代表块，随后补同源块；触及上限会明确报告，不能把未匹配当作已排除全部冲突意见。

本轮还修复文本固定字节窗口截断 UTF-8 字符的问题：跨窗字符完整归前窗，后窗从下一完整字符开始，引用使用实际字节边界。读取器版本加入文本引用，旧版可能丢汉字的缓存保留历史但不进入当前建议，须重新读取/导入。普通文件工具默认字节游标行为保持。

验证包括中文固定事实及两个冲突来源、专家/测量分类和条件、第二任务授权复用、角色/公开/无输入范围、真实用户事件和无记忆自动写入、来源改版及不可变旧快照、导入重放/去重、伪造授权拒绝、快照损坏/撤销、30 个旧版本不会挤掉当前命中、多页共享快照、跨页完整汉字、旧缓存拒绝、分页与普通读取保持。8 项首批检查通过，两个实际修正项复查通过；读取器版本补充的旧缓存拒绝与 UTF-8 跨页检查通过。未重跑既有记忆、模型评测、依赖/作业或全量回归。

真实 Edge 界面 v2 单项通过：导入两份私密中文指导，第二任务检索保留相反意见与条件，源改版后过滤旧建议、读取旧快照、重新导入新版并显示替代，桌面/手机截图已查看。它使用独立 `workspace/knowledge-ui-20261010-v1`、关闭 Agent，没有写生产知识或经验。首轮仅因测试的下拉框定位方式不匹配而超时，没有知识导入；原 v1 失败保留，按实际可访问角色修正后单项复查。最后读取器版本标记和旧缓存提示的增量由定向后端检查及构建覆盖，原前端导入/检索契约不变。

这是 AC-09 操作与检索层的实现和局部证据，不代替真实模型“导入指导→完成任务→明确记忆变更→后续任务使用”的联合验收，也不代表阶段 1 其他出口已完成。
