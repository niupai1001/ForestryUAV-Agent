# Agent 交接记录目录

当前仅建立协议入口，**未认领代码修改、未登记任何运行资源占用、未启动其他 Agent**。

每个 Agent 先读 [共同约定](../AGENT-WORKING-AGREEMENT-zh.md) 和 [当前执行计划与源码实现指导](../AGENT-IMPLEMENTATION-PLAN-20261022-zh.md)，再按共同约定中的模板创建自己的 `<任务ID>-<Agent标识>.md`。接续已有工作，具体测试只作为问题样本；任务标识可用组件名，旧 E 编号仅作交接追溯，不强制逐卡推进。

请在记录中写明现有协调/集成负责人及其已分配范围。一个负责人统一分配；多人同目录未经分配时只能只读。不要把本目录的文件存在性当作互斥锁，也不要用时间推测另一个 Agent 已退出。

交接记录是证据，整体完成度仍以 [DELIVERY-TRACKER.md](../DELIVERY-TRACKER.md) 为准。本目录不存数据集、密钥或完整模型输入。
