Official PyPI metadata binds release, non-yanked file, size and SHA; bytes may come from official files or TUNA. Exact URLs, global pinned DNS, TLS, approval/source version/revision/control and revocation are checked for each request. Ambient proxies/credentials and local file uploads are excluded. Private contexts use existing exact approvals. Immutable wheels, metadata and locks retain provenance; same-origin hashes are not independent signatures. Downloads never import, unpack or execute packages.

prepare_environment accepts acquired wheel_artifact_ids alongside authorized wheel_refs, at most 32 total, through existing offline Jobs/pip/hash/transitive-dependency checks. Inputs must match a confirmed acquisition in the current task revision and its artifact/hash. Roles need explicit artifact grants; submission/queue/start verify read-only inputs. Extended-path I/O supports long Windows filenames. Fresh IDs for identical downloads are not progress. Models still choose precise versions and a complete wheel set; candidate/automatic resolution, source builds and stable compound tasks remain pending.
