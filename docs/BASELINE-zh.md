# 修订后的实施基线 · 1.6

本项目独立重新开发，不复用或迁移旧 ForestryUAV-Agent 代码与数据。原始项目书副本为需求依据；本文件记录经审查及用户选择后的修订。中文为当前权威来源，英文译本共享版本号。

2026-10-06 用户指示“关于Agent的联网搜索功能可以先不开发”。联网搜索新增开发与验收暂缓，已有实现及安全边界保留；当前先交付本地通用能力。相关门槛标记用户暂缓，不计为通过，也不阻塞本轮本地通用能力验收。其余阶段、领域流程、评估及规模要求继续保留。

## 保留范围

R01–R16 与 U01–U08 保留。先交付完整通用 Agent 与可用本地 UI，再实施影像/LiDAR 两条真实流程，最后通过六组合、低资源与真实 ≥100 GB 规模验收。允许前期核验领域工具和公开数据可行性，不提前开发领域功能。

角色长期配置、按需隔离委派，不强制部门顺序。没有独立现场真值时，允许有明确支持和局限的内部检查产品，不声称已验证精度。绿色代理不能代替冠层覆盖。低资源硬件由用户在 pilot 后确定；未冻结及实测前，不宣布完整 V1。

## 必须修正的契约

1. 第 6 节节点改为行为职责，采用 PydanticAI/Harness 原生循环、检查点和压缩，不另建 LangGraph 循环。
2. 首次副作用前持久保存动作、attempt、输入和授权身份；完成调度器不是登记动作的前提。
3. 普通消息不改变任务规范修订；目标/输入/方法/约束变化使用独立 amendment。状态版本与规范修订分开。
4. 候选文件和清单先验证，形成验收记录后封存最终清单并发布，对账后提交终态。清单不递归哈希自身。
5. 统一指标字段 spatial_support_ref。外部类型只在真实边界增量添加，不预建每条记录的 service/repository。
6. WP 管实施，AC 管验收，DOM 映射 WP；通用和领域共用执行、资源、事件、报告和交付机制。
7. 框架记录模型历史/检查点；应用 SQLite 记录任务、授权、动作、作业、证据、验收。框架检查点不授予成功或权限。
8. 私密上下文产生的外传查询需范围授权；网页读取拒绝私有/回环地址及不安全重定向；报告预览隔离脚本和网络。
9. 公开/持久化输入拒绝多余字段；源数据只读；不接受模型制造的用户授权事件；取消以实际执行端回执为准。
10. 新任务冻结 max_unchanged_decisions；应用持久记录工具观察，在同一任务修订/逻辑用户回合/角色内跨运行和重启累计。重复观察、失败与空末尾窗口达到上限时返回 NO_PROGRESS 并暂停；已确认副作用保留。直接恢复不能清零，认证用户补充纠正说明后才可以停止旧回合并启动新的纠正回合；任务累计预算不重置。目标/输入/方法/约束改变仍通过 amendment。观察新颖性不能代替语义验收。

11. TaskConstraints.allowed_capabilities 为已注册能力的唯一列表；省略或 null 继承配置上限，空列表禁止全部注册动作。显式范围必须同时约束原生工具展示、实际执行、作业提交/启动及角色委派交集，不能由普通消息或模型扩展。原生溢出读取只访问该运行已有的工具结果，不授予新的文件、网络或执行能力。修订未提交 constraints 时保留原范围；明确提交 {} 时继承配置上限。修改目标、输入及工具范围使用 UI 规范修订并暂停旧执行，再经对账恢复。

12. 修订保留未改动的输出偏好、指标请求及冻结字段。控制请求重传只能返回原回执；暂停/修订/取消不能停止后来回合的执行令牌，恢复重传不能创建新模型回合。

13. 可配置项目独立 WSL Docker 传输，固定发行版、显式 guest Unix socket 和项目私有客户端配置；清除宿主凭证/代理/WSLENV，guest 使用 env -i，无 shell 解释生成代码。只转换已授权本地绝对盘符挂载路径，拒绝 UNC/相对路径，不重置现有 Docker/WSL 数据。签名镜像、固定系统包和 Python 镜像摘要分开锁定。生成代码仍使用同一 Jobs 控制/身份/资源机制，终态 wait_job 带真实有界日志，便于错误修复。

14. 启动对账事件记录任务修订、逻辑回合、原状态及阻塞原因。恢复后逐次向同一回合重新注入这一应用记录；H0/H1/H2 共享此控制事实，子角色不接收父任务的记录。新回合、其他任务/修订及无明确回合的旧事件不能作为当前恢复事实。应用启动记录本身不证明进程崩溃、容器持续运行或计算正确，仍需独立执行证据。

1.6 保留1.5的本地及领域范围、用户暂缓联网搜索和独立 WSL 执行器，补充有范围的应用恢复事实；应用元数据库版本仍为2，仅扩充既有事件载荷，无须新的运行状态存储。

## 实施批次

P0：修订和可行性；P1：真实 UI/模型/文件闭环；P2：受限执行与恢复；P3：完整通用产品；P4：影像；P5：LiDAR；P6：冻结实验、规模与发布。每批独立记录实现、验证、失败和证据，不以目录/截图/退出码代替行为验收。

## 当前尚待验证

独立 WSL 容器的合成计算、取消/超时已实测，大模型代码调试 UI 通过；小模型原调试试次遗漏报告读回，仍未通过。两模型的真实服务进程中断试次均通过14项检查：已确认提交的运行中作业跨重启保持同一身份、不重复执行、结果及报告实际读回。该单点夹具不能替代完整恢复/UI/报告质量验收；模型报告对实际中断仍有含混描述。范围依赖、完整恢复边界、两个模型完整通用任务/上下文质量、兼容原始 UAV LiDAR 与地形、真实 ≥100 GB 数据、低资源硬件及 pilot 后发布容差仍待验收。联网搜索按用户指示暂缓。源码存在不代表这些门槛通过。
